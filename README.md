# ⏱️ Stopwatch Web Application
[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://kimtia18.github.io/Task-02-Stopwatch/)

[![GitHub](https://img.shields.io/badge/GitHub-Repository-black)](https://github.com/kimtia18/Task-02-Stopwatch)
A responsive and interactive stopwatch web application built using HTML, CSS, and JavaScript.

## 📌 About the Project

This stopwatch application was created as part of my Web Development Internship at Prodigy InfoTech.

The project demonstrates how JavaScript can be used to create real-time functionality and handle user interactions in a web application.

## ✨ Features

- ▶️ Start the stopwatch
- ⏸️ Pause the stopwatch
- ▶️ Resume from the paused time
- 🏁 Record lap times
- 🔄 Reset the stopwatch
- Prevents multiple timers from running simultaneously
- Responsive design for desktop and mobile devices
- Modern glass-style user interface
- Smooth hover and transition effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- VS Code
- Git
- GitHub

## 📱 Responsive Design

The application is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.

You can also open `index.html` directly in a web browser.
